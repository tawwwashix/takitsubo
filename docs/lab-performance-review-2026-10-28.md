# エピソード研究所の読み込み改善・検証記録

2026-10-28。比較元は `f0364521`。画像ファイル、画像URL、保存キー、抽選ルールは変更していない。

## 変更

- エピソードデータを研究所のJS/CSSと並行して取得する。
- 3択の画像取得を共有UIより先に開始し、共有PNG生成モジュールは生成操作時に読み込む。
- 3枚の画像の取得・展開が揃うまでケースを非表示・操作不可にし、「カートリッジを準備中…」を表示する。準備完了後、絵の入った3本を同時に表示する。
- 引き直し・離脱は古い画像準備を中止する。取得失敗・タイムアウトは既存画像、さらに内蔵の代替表示へ切り替える。
- 閉じた図鑑は一覧を描画せず、開いた後は項目を再利用する。登録や引き直しで変更のない3択・手持ちを再生成しない。
