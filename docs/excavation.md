# 滝壺発掘 プロトタイプ

`excavate.html` をローカルHTTPサーバー経由で開く。ホームの導線とフッターからも移動できる。

博士から3択を選ぶ別案は `start-episode-lab.bat` で起動できる。[エピソード研究所の説明](episode-lab.md)を参照。

- クリック・タップでひと払い。押しながらなぞると連続して砂を払える。
- 「砂をひと払い」ボタンはキーボードにも対応し、まだ覆われた場所を払う。
- アートワーク領域の42%以上が見えたら「取り出す」。残りの砂を落とし、タイトルと個別ページへのリンクを表示する。
- 制限時間、失敗、待機、聴取状態の記録はない。
- 第0回を除く既存 `data/search.json` の全エピソードが対象。最新回も含む。
- 砂浜ごとに異なる3回を配置。各候補は未発見があるとき80%の確率で未発見プール、残り20%で全候補から抽選する。そのため未発見の実際の出現率は80%以上になる。候補を作り直すときは直前に取得した回を除外する（対象回が3回以下の場合を除く）。
- 図鑑は `localStorage` の `takitsubo:excavation:v1` に回番号の配列を保存する。端末・ブラウザ・オリジンごとに独立。保存不可時も画面内では遊べる。ローカル試作の図鑑は公開サイトへ移行しない。

## 構成

`scripts/build.py` にページ生成と導線を追加。共通 `excavate-loader.js` は発掘ページに限り
`assets/js/excavate/game.js` と `assets/css/excavate.css` を読み込む。
専用ファイルもナビゲーションのバージョン判定に含める。
エピソードの原本、RSS更新処理、配信プレイヤーに変更はない。

128×128のマスクを発掘状態として保持し、画面サイズが変わっても掘った場所を保つ。
砂のテクスチャはリサイズ時に生成。砂粒のアニメーションは操作時のみ動き、離脱時に終了する。
動きを減らす設定では砂粒と遷移アニメーションを省略する。

## ローカル確認

通常の手動確認は、Worktree直下の **`start-excavation.bat` をダブルクリック**する。
既定ブラウザで `http://127.0.0.1:8766/excavate.html` が開く。
作業ディレクトリに依存せず、バッチが置かれたWorktreeを表示する。
サーバーのウィンドウを閉じるかCtrl+Cで終了する。ショートカットをデスクトップへ置く場合も、バッチ本体は移動しない。

- 同じWorktreeのサーバーが起動済みなら再利用し、ブラウザを開く。
- 同じポートで別のサーバーが動いていれば、別のサイトを誤表示せずエラーで停止する。
- ローカルPC限定。main、ビルド、RSS、Git操作には触れない。
- 図鑑は同じブラウザの同じURLなら終了・再起動後も残る。従来の8765番と今回の8766番では保存領域が異なる。
- 更新後はブラウザを再読み込みする。サーバーはキャッシュしないレスポンスを返す。
- 詳細な起動オプション: `start-excavation.bat --no-browser` / `start-excavation.bat --port 8767`。

開発・自動テストの場合:

```text
python scripts/build.py
python -m http.server 8765 --bind 127.0.0.1
node scripts/test_excavate.cjs
```

テストはPlaywrightとChromeを使う。必要に応じて既存のPlaywrightへ `NODE_PATH` を設定する。
GAへの通信を遮断し、レポートとPC・モバイル画面の画像を `.local-preview/` へ出力する。
実機のiOS Safari・Androidでの指の感触、動作性能は別途確認する。

## 選択と追加発見の試作（2026-10-23）

- 3か所のプレビューを押して選択。払った砂・取得状態・追加発見は場所ごとに維持する。
- 同じ砂浜の3枚をすべて取ることもできる。日数・個数制限は設けない。
- 「別の砂浜へ」は候補と未取得の発掘途中状態を新しくする。取得済みの図鑑は保持する。
- 3か所のうち1か所に小物が埋まる。22%以上払うと砂が崩れ、絵が少し広く見え、小物が現れる。演出待ち・操作失敗はない。
- 小物はアートワークを取り出したときに保存。貝殻・シーグラス・小石・星のかけらの4種を、別キー `takitsubo:excavation:finds:v1` に保存する。既存の図鑑キー・形式は変更しない。
- 「おまけの発見を楽しむ」で未発生の追加発見をオフにできる。既に見つけた小物は失わない。設定はページ内のみ。
- 図鑑登録済みの候補は18%以上見えるとその旨を表示する。
- `node scripts/test_excavate_choices.cjs` で選択・途中状態・追加発見のオンオフ・小物の永続化・無制限の再抽選を検証する。固定乱数はテスト側のみで注入し、本体にはテスト専用操作を追加していない。
