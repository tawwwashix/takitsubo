# 公開前の改善4件

対象は `1e4bfad3` 以降のローカル変更。ユーザー承認済みの4件を実装し、コミットまで行う。リモートへのpush、GitHub Actionsの起動、公開環境の変更は行わない。

## 実装

1. **自動更新の公開前チェック**: AWQ/RSS更新前に入力検証、生成後に生成物検証とPython回帰テスト3本を実行する。失敗すると既存の自動コミット・pushステップへ進まない。
2. **入力JSONの一括検証**: 入力9ファイルをビルドの読み込み段階で検証する。型、必須値、重複キー・回番号、企画・おすすめ回の参照、日付、画像パスを確認し、不正入力では生成物を書き換える前に停止する。歴史的なAWQの `round: null` と省略画像は許容する。
3. **トップの検索入口**: 番組説明とおすすめ回の間に検索欄を追加。ゲーム名・回番号から既存のエピソード一覧へ進む。ゲーム索引への補助リンクにも入力を渡す。音声再生を保ったページ移動を利用する。
4. **404ページ**: 共通ヘッダー・フッター、中央のダチョウ、検索、ホーム・一覧リンクを配置する。深いURLでも画像・リンクが動くルートからのパスを使用。自動転送せず、noindexを付け、canonical・サイトマップから除外する。通常ページへの移動ではnoindexを解除する。ローカルプレビューもHTTP 404で同じページを返す。

`data/game_readings.json` にあった同じ値の重複キー「時速1000kmの牛」を1件削除した。JSONとして読み込まれる辞書は変更前と一致する。

### ブラウザ確認の注意点

最初の全体実行では、研究所の選択テストで320px幅のカートリッジ境界判定が一度失敗した。単独再実行と同じ320px条件の8回反復では再現せず、全体再実行でも該当テストは成功した。最初の失敗原因は未特定。判定を緩めず、次回失敗時に各辺の位置を記録するよう診断情報を追加した。研究所の表示コードはこの改善では変更していない。

全体再実行ではカードテストの第128回音声の開始待ちが60秒でタイムアウトした。同じテストの個別再実行は、実音声の継続・戻る操作を含めて成功した。したがって「全体を一度で22/22通過」ではなく、「全体21/22＋失敗した1本の再実行成功」が最終結果。元の全体ログは `.local-preview/suite-report.json` と各テストのログ、カード再実行は `.local-preview/test-episode-cards-rerun.log` に残す。

GitHub Actions上の実行と公開先での404配信は未検証。ローカルではプレビューの実際のHTTP 404レスポンスを使う。JavaScript無効時も検索フォームで一覧へ移動できるが、一覧の絞り込み自体は従来どおりJavaScriptに依存する。
