# トップページの泡の位置を調整する

編集するファイルは `assets/css/style.css`。
「トップの泡の位置調整」で検索すると、`.route-bubbles` の設定欄が見つかる。
対象は画面幅1051px以上。821〜1050pxの2列表示と、820px以下の縦並びには影響しない。

## 数値の意味

平行四辺形の基準位置から、各泡を何px動かすかを指定する。
`x` はプラスで右／マイナスで左、`y` はプラスで下／マイナスで上。
必ず `px` を付ける。基準位置そのものは下にあるグリッド設定が担当しているので、通常は触らなくてよい。

| 泡 | 横位置 | 縦位置 | 初期値 x / y |
| --- | --- | --- | --- |
| 滝壺DB | `--route-db-x` | `--route-db-y` | `0px` / `0px` |
| ゲーム診断 | `--route-shindan-x` | `--route-shindan-y` | `0px` / `0px` |
| AWQ | `--route-awq-x` | `--route-awq-y` | `0px` / `-12px` |
| 研究所 | `--route-lab-x` | `--route-lab-y` | `0px` / `-12px` |

例：研究所を今より30px左、20px上へ動かす場合。

```css
--route-lab-x: -30px;
--route-lab-y: -32px; /* 初期値 -12px から、さらに20px上 */
```

ホバー時は調整した位置から6px浮く。通常時とホバー時を別々に編集する必要はない。
泡の大きさ、文字、表示順は変わらない。

## 確認する

1. Worktree内の `start-episode-lab.bat` でプレビューを起動する。起動済みならそのままでよい。
2. 表示されたローカルURLのトップページ（`lab.html` を取り除いたURL）を開く。
3. PC用の配置が出る幅にブラウザを広げる。DevToolsを使う場合はページ側の幅を1051px以上にする。
4. CSSを編集・保存し、ブラウザで再読み込みする。反映が見えなければ `Ctrl+F5`。
5. 泡にマウスを重ねた状態と、少し狭いPC幅でも確認する。

ローカルプレビューは `Cache-Control: no-store` なので、CSSの数値を試すたびのビルドやサーバー再起動は不要。
配置が決まり、公開用の生成HTMLを更新するときだけ `python scripts/build.py` を実行する。
これは共通CSSの参照バージョンを全ページに反映するための処理。今回の調整用変更では実行していない。

## 余白の調整

移動量は見た目の位置だけを変え、前後のセクションを自動では押し広げない。
大きく上へ動かす場合は `--route-space-top`（初期値 `20px`）、下へ動かす場合は
`--route-space-bottom`（初期値 `44px`）を増やして、上下のコンテンツとの間隔を確保する。
上の余白を増やすと、泡全体も下へ移動する。
横へ大きく動かすと画面外にはみ出すので、まずは10〜20pxずつ調整する。
